# Four-Bar Linkage Synthesis Tool

An interactive mechanism synthesis tool that generates four-bar linkage mechanisms capable of passing through four user-defined precision points.

The project combines numerical optimization, Burmester graphical construction, and real-time visualization to study coupler curve generation and mechanism motion.

---

## Features

- Exact four-position synthesis using numerical optimization
- Burmester graphical construction method
- Interactive precision point input
- Coupler curve visualization
- Mechanism animation
- Automatic parameter search
- Closure error verification

---

## Concepts Used

- Four-bar linkage synthesis
- Coupler curve generation
- Kinematics of machines
- Burmester theory
- Nonlinear least squares optimization
- Geometric constraint solving

---

## Technologies Used

- Python
- Streamlit
- NumPy
- SciPy
- Plotly

---

## How It Works

1. User inputs four precision points
2. The program computes feasible linkage configurations
3. The mechanism is synthesized and visualized
4. Motion is animated to verify coupler path generation
